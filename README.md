# 토닥

가족이 어르신의 안부와 인지 웰니스를 함께 살펴보는 iOS·Android 앱 프로토타입입니다. Expo와 React Native의 네이티브 화면 구성요소로 만들었습니다.

## 화면

- 보호자 대시보드와 예시 통화 요약
- 주간·월간 대화 흐름 리포트
- 인지 웰니스 활동 체크
- 치매안심센터·보건소 안내

통화 기록, AI 분석 결과, 위치 검색은 시연용 예시입니다. 실제 통화 처리, AI 분석, 알림 전송, 위치 검색, 의료 진단은 연결되어 있지 않습니다.

## 실행

```sh
npm install
npm run start
```

Android 에뮬레이터에서는 `npm run android`, iOS 시뮬레이터(macOS)에서는 `npm run ios`를 사용할 수 있습니다.
